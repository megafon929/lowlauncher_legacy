# LowLauncher v1.2 (Android 4.0.4 – 7.1, API 15–25)

[English](README.md) · **Русский**

## Описание
LowLauncher — лёгкий лаунчер для Android 4.0.4 – 7.1 на чистой Java, без внешних библиотек. Пакет `com.m929.lowlauncher`.

- **Рабочий стол:** настраиваемая сетка (4×4 … 5×6; по умолчанию 4×5, на коротких экранах 4×4), 5 страниц, перетаскивание ярлыков и системных виджетов (выбор, размещение, изменение размера, удаление), меню по долгому нажатию (виджеты, обои, настройки), свайп вниз — шторка уведомлений.
- **Папки (новое в 1.1):** перетащите значок на другой значок — создастся папка, на папку — значок добавится в неё. Нажатие открывает папку, название редактируется сверху, долгое нажатие на значке внутри — вынуть его (на рабочий стол, в Dock или в «Удалить»). Папка с одним приложением снова становится обычным значком.
- **Dock:** ровно 5 мест, общий для всех страниц, без кнопки меню, пустые места разрешены.
- **Меню приложений:** свайп вверх из любого места, полупрозрачный фон, поиск, настраиваемое число колонок.
- **Перетаскивание:** зоны «О приложении» и «Удалить», автопрокрутка страниц у края.
- **Настройки:** сетка, колонки меню, набор иконок (Icon Pack ADW/Nova/Apex/Go), размер шрифта.
- **Совместимость:** minSdk 15 (Android 4.0.3/4.0.4), targetSdk 25 (Android 7.1). На Android 4.1+ виджеты выбираются из собственного списка лаунчера и привязываются через AppWidgetManager; виджетам сообщается их размер.
- **Локализация:** английский, русский и ещё 44 языка Android 4.0.4 (47 локалей, см. «Языки»).
- **Сборка:** Gradle, R8, аппаратное ускорение.

## Сборка
Нужны JDK 17+ и Android SDK с платформой 34 и build-tools (их ставит Android Studio).

    ./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
    adb install -r app/build/outputs/apk/debug/app-debug.apk

Запуск из Android Studio: лаунчер — это домашний экран, у него нет значка (категории LAUNCHER), поэтому обычный «Run» выдаёт «Default Activity not found». В Run → Edit Configurations → Launch Options выберите «Specified Activity» и `com.m929.lowlauncher.Launcher` (или «Nothing» — только установить), затем на устройстве нажмите «Домой» и выберите LowLauncher.

Release собирается с R8 (minify + shrinkResources, правила в app/proguard-rules.pro).
Gradle 8.7 (wrapper) + AGP 8.5.2. Системный Gradle 9 с AGP 8.5 не дружит — запускайте `./gradlew`.
`compileSdk 34` нужен только сборщику; `minSdk = 15`, `targetSdk = 25`.

Проверка компиляции против android.jar платформы (рекомендуется android-25):

    scripts/check-api.sh /путь/к/android-25/android.jar

Вызовы API 16+ стоят под проверкой `Build.VERSION.SDK_INT`, поэтому при компиляции с android-15 ошибки будут только на них.

После установки нажмите «Домой» и выберите «LowLauncher» → «Всегда».

## Управление
- Свайп вниз по рабочему столу — шторка уведомлений.
- Свайп вверх с любого места рабочего стола или Dock — меню приложений; вниз (когда список наверху) или «Назад» — закрыть.
- Долгое нажатие на пустом месте — «Добавить виджет» / «Обои» / «Настройки».
- Настройки: сетка рабочего стола (4×4 … 5×6), число колонок в меню приложений, набор иконок, размер шрифта подписей (любой установленный Icon Pack формата ADW/Nova/Apex/Go; для приложений без иконки в наборе применяются фон/маска набора).
- Поиск вверху меню приложений скрывает неподходящие приложения по мере ввода.
- Долгое нажатие на значок/папку/виджет — перетаскивание (края экрана листают страницы).
  Из меню приложений значок перетаскивается на рабочий стол, на Dock или на другой значок/папку.
- Папки: бросьте значок на середину другого значка — получится папка; нажмите — откроется; название меняется сверху; долгое нажатие на значке внутри вынимает его.
- Виджет после размещения (или после отпускания) получает рамку: ручки на сторонах меняют размер
  по ячейкам, красный кружок удаляет.
- Dock на 5 мест; при первом запуске заполняется (телефон, SMS, браузер, камера, музыка), дальше места могут быть пустыми.
  Значок Dock можно перенести на рабочий стол, в «Удалить» или заменить другим.
- При перетаскивании значка сверху две зоны: «О приложении» (системные сведения) и «Удалить».

## Устройство (app/src/main/java/com/m929/lowlauncher)
- `Launcher` — активность: модель, виджеты (AppWidgetHost), папки, меню, операции drop.
- `DragLayer` — корневой слой: жест меню приложений и drag&drop.
- `Workspace` + `CellLayout` — 5 страниц с настраиваемой сеткой (по умолчанию 4x5, 4x4 на экранах ниже 590dp).
- `Dock`, `AppDrawer`, `IconView`, `PageDots`, `ResizeFrame`, `HomeWidgetView`, `FolderPopup` (открытая папка), `FolderDrawable` (значок папки).
- `LauncherModel` (PackageManager, наборы иконок, иконки приводятся к размеру launcher icon), `Store` (SharedPreferences).
- `ItemInfo` / `AppInfo` (данные), `U` (вспомогательные функции); `scripts/check-api.sh` — проверка компиляции против android.jar платформы.

## Языки
Название везде «LowLauncher». Интерфейс переведён на 47 локалей Android 4.0.x: английский по умолчанию и 46 папок `values-*` (ru, uk, be, de, fr, es, it, pt, pl, cs, sk, ja, ko, zh-CN, zh-TW, ar, he, fa, hi, th, vi и др.), то есть 46 языков, китайский в двух вариантах; см. `app/src/main/res/values-*`. Переводы сделаны автоматически — носителям стоит проверить формулировки.

## Аппаратное ускорение
Включено в манифесте (`hardwareAccelerated`). На время анимаций (меню приложений, листание страниц, перетаскиваемый значок) view временно получают аппаратный слой GPU и снимают его после окончания, чтобы не занимать память.

## Статус
Идея и техническое задание — автора; код сгенерирован с помощью Claude (Anthropic). Версия 1.0 проверена на реальном устройстве; изменения 1.1 и 1.2 (папки, адаптация под Android 7.1, исправления) проверены компиляцией и ещё требуют проверки на устройствах. Отдельная сборка для Android 9–17 лежит в `launcher-new`.

## История версий
- **1.2** (сборка 3) — исправление ошибок.
  - **Раскладка не теряется:** значки временно недоступных приложений (карта памяти, система ещё грузится, отключённое приложение) и не поместившиеся после уменьшения сетки больше не стираются; они возвращаются, когда это возможно.
  - **Исправлено:** нет дублей в Dock; значки и названия обновляются после обновления приложений; верные названия виджетов на Android 5.0+; рабочий стол не становится прозрачным, если нажать «Домой» во время открытия меню приложений; пустой список приложений при запуске системы перезапрашивается; нет пустого экрана после возврата из окна «О приложении».
- **1.1** — адаптация под Android 4.0.4 – 7.1 и папки на рабочем столе.
  - **Папки:** бросьте значок на другой значок — создастся папка; её можно открыть, переименовать и вынуть из неё значки.
  - **Android 4.0.4 – 7.1** (targetSdk 25): собственный список и привязка виджетов на Android 4.1+, виджетам передаётся их размер.
- **1.0** — первый выпуск.
